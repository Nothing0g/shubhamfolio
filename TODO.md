# Delivery outcomes

- Build a complete React + Vite + TypeScript static front end with React Router routes for `/`, `/about`, `/work`, `/contact`, `/accessibility`, `/work/:slug`, and a 404 fallback; keep all pages content-driven and use one route file per page in `src/pages`.
- Implement plain CSS only with readable BEM class names, colocated section styles, design-token-based colors/fonts/spacing/radii/shadows, generated `tokens.css`, and a README mapping tokens to WordPress and HubSpot theme settings.
- Implement the warm cream, ink-dark, cobalt/coral/yellow visual system; Bricolage Grotesque, Plus Jakarta Sans, and Kalam typography; prop-driven sections; lowercase `shubham` logo with coral dot; illustration placeholders; and accessible inline SVG icons.
- Implement semantic, WCAG 2.2 AA-aware shared layout with skip link, one h1 per page, keyboard focus, responsive 360–1920px layout, mobile drawer below 1024px with focus trap/Escape/backdrop close/body scroll lock, reduced-motion handling, visible pause controls, alt text, and accessibility statement.
- Implement Home with hero, statement, selected work, four-step process, capabilities marquee with pause control, and CTA band using calm original copy and the three supplied case-work themes.
- Implement About, Work with filter chips, Contact with browser validation and success/error states calling `submitContact(values)`, Accessibility, and a useful 404 page.
- Implement three 600–900 word case-study entries and a shared `/work/:slug` template with CaseHero, overview, problem, opportunity, ownership, constraints, research, approach/gallery, solution, results, quote, reflections, and NextCase sections.
- Implement per-route SEO metadata, canonical/OG/Twitter tags, JSON-LD without placeholders, route manifest, sitemap, robots, favicon/manifest icons, and descriptive image/alt metadata.
- Run `npm run build` and `npm run test`, fix failures, verify the preview at desktop/mobile widths, and publish or prepare the static output for a free GitHub Pages deployment.
